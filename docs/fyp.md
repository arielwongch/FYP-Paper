Title: Exploring and Optimizing Memory Architectures for LLM Agents - 1

Category: Artificial Intelligence

Type: Final Year Thesis (FYT)

Target student: COMP/+AI/Tsinghua

Project Description:
Large Language Model (LLM) agents can perform multi-step reasoning, interact with tools, and support long-horizon tasks. However, as interactions become longer or span multiple sessions, a key challenge is memory: what information should be stored, how should it be updated, and how can past information be retrieved efficiently and accurately?

This project studies memory architectures for LLM agents from both algorithmic and systems perspectives. The student will build a modular agent framework with interchangeable memory modules, such as sliding-window memory, summary memory, retrieval-based memory, structured fact memory, and hybrid designs. The project will compare these memory mechanisms on long-horizon or multi-session tasks, and evaluate both task quality (e.g., recall, consistency, knowledge updating, and task success) and system behavior (e.g., latency, retrieval overhead, storage growth, and scalability as history grows).

Depending on progress, the student may further design a lightweight adaptive memory strategy to decide when the agent should write memory, summarize history, or retrieve past information under efficiency constraints. This project focuses on system design, inference-time memory management, and experimental evaluation, rather than large-scale model training, and is therefore feasible with modest computing resources.

Skill: Python programming, basic machine learning/LLMs knowledge, and interest in experimental evaluation and system implementation.
